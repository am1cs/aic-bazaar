# Synthetic creative fixtures

GLOW is a fictional brand. These files are synthetic examples created by the
project team to demonstrate milestone submission, file fingerprints and payment.
They are not paid customer work, creator recruitment, or market traction.

- concept.svg: three keyframes with the planned scene order.
- draft.mp4: 15-second vertical draft with a DRAFT label.
- final.mp4: 15-second 1080x1920 MP4 with the agreed call to action and no draft label.
- hashes.json: SHA-256 fingerprints of the exact files used for the seeded deals.

Generate with `python3 deployment/generate-demo-assets.py` on macOS with ffmpeg
installed. The script uses Arial Bold; adjust its font path for another OS.
Files are committed so recreating them is optional. The frontend owner may reuse
these files or replace them with better original samples for the product video.
